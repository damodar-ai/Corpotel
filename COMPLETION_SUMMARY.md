## 🚀 Quick Start

### 1. **Set Up Database** (2 minutes)
```bash
mysql -u root -p < backend/database/schema.sql
```

### 2. **Configure Environment**

**backend/.env:**
```
DB_USER=root
DB_PASSWORD=your_password
```

**frontend/.env** (already configured)

### 3. **Start Development** (1 minute)
```bash
npm run dev
```

Backend: http://localhost:5000
Frontend: http://localhost:3000

### 4. **Login & Explore**
```
Email: admin@corp-hotel.com
Password: admin@123
```

2. **Frontend won't load**: Verify backend is running on correct port
3. **Build errors**: Run `npm install` in both directories
4. **Port in use**: Change ports in config files
